# Instructions for Claude

## Dates and time-sensitive facts: current only, checked twice

Standing request from the repository owner (given 2026-11-16).

- Any date, deadline, validity period, threshold or rule that can change over time must be current at the moment of answering.
- Before stating it, confirm it against at least two independent, recent sources. Prefer the primary or official source, and check that the page itself is not stale (official pages are sometimes left un-updated after a newer decision).
- Say what date each source is from.
- If only one source could be found, or the sources disagree, say so explicitly instead of presenting the value as settled.

Why: an outdated date taken from a stale official page was once given without a second check, and had to be corrected afterwards.

Scope: the owner phrased it generally ("only current dates, double-check"). Reading it as covering all time-sensitive facts, not one topic, is Claude's interpretation.
